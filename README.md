# PTA6

A pixel-styled open-world city game that runs in the browser. One HTML file, no build step. Built as a dense GTA-style loop: story chapters, side jobs, respect, wanted heat, collectibles, and 100% completion.

**Play:** https://pta6.vercel.app

## Controls

| Key | Action |
|---|---|
| WASD | Move, drive, swim |
| Mouse | Look and aim |
| Left click / Space | Attack (Space = handbrake in car) |
| Right mouse / X | Aim |
| R | Reload on foot, radio in a car |
| 1-7 / Q / wheel | Switch weapon |
| F or E | Enter/exit vehicle, talk, gym/food/casino/club |
| F near tag | Spray graffiti |
| J | Side job / cancel |
| Y | Rampage at skull markers |
| T | Phone |
| M | Map |
| B | Buy / export / crush |
| V | Store car at owned safehouse |
| P | Pause and 100% stats |
| G | HD or pixel graphics |

## GTA loop

- **Chapter 1 Vinny (pink)** → **Chapter 2 Rico (cyan)** → **Chapter 3 Lena (lime)**
- Side jobs: taxi, vigilante, paramedic, firefighter, pizza (bike), tow (truck), night burglary, street race
- Respect ranks, turf wars, spray tags, rampages, stunt jumps
- Gym / food stats (stamina, muscle, fat), casino, club dating, import-export, crusher
- Collectibles: gold stars, oysters, hidden bribe stars
- Six wanted stars with army trucks, roadblocks, helicopter
- Phone: hits, chop shop, export list, GPS contacts
- Completion % toward 100% city clear

## Run locally

Open `index.html` in a browser. It loads three.js from a CDN, so it needs an internet connection.
