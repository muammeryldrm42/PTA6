# PTA6

A pixel-styled open-world city game that runs in the browser. One HTML file, no build step.

**Play:** https://pta6.vercel.app

## Controls

| Key | Action |
|---|---|
| WASD | Move, drive, swim |
| Mouse | Look and aim (shots go where the crosshair points) |
| Left click / Space | Attack (Space is the handbrake in a car) |
| Right mouse / X | Aim |
| R | Reload on foot, radio in a car |
| 1-5 / Q / wheel | Switch weapon |
| F or E | Enter or exit a vehicle |
| Shift | Sprint |
| C | Jump |
| T | Phone |
| M | Map and waypoints |
| B | Buy |
| P | Pause and stats |
| G | HD or pixel graphics |

Touch controls appear automatically on phones and tablets.

## Run locally

Open `index.html` in a browser. It loads three.js from a CDN, so it needs an internet connection.
