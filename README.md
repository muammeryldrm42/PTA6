# PTA6

A pixel-styled open-world city game that runs in the browser. One HTML file, no build step.

**Play:** https://pta6.vercel.app

## Controls

| Key | Action |
|---|---|
| WASD | Move, drive, swim |
| Mouse | Look and aim (shots go where the crosshair points) |
| Left click / Space | Attack (Space is the handbrake in a car) |
| Right mouse / X | Aim |
| R | Reload on foot, radio in a car |
| 1-5 / Q / wheel | Switch weapon |
| F or E | Enter or exit a vehicle |
| Shift | Sprint |
| C | Jump |
| T | Phone |
| M | Map and waypoints |
| B | Buy |
| F near Vinny (pink) | Story missions, then repeat contracts |
| J | Side job, or cancel the current one |
| V | Store the current car at a safehouse you own |
| P | Pause and stats |
| G | HD or pixel graphics |

Touch controls appear automatically on phones and tablets.

## City work

Vinny stands on the pink marker. Eight story jobs pay out, then he keeps offering contracts. Press J in a taxi, police car, ambulance, or fire truck for side work, or at the orange race marker for a street race. Three gangs hold turf; draw a gun on their block and clear the crew to take it. Owned blocks pay with your properties. At three wanted stars the police drop roadblocks. A safehouse garage keeps one car and the phone brings it back.

## Run locally

Open `index.html` in a browser. It loads three.js from a CDN, so it needs an internet connection.
