# PTA6

A pixel-styled open-world city game that runs in the browser. One HTML file, no build step.

**Play:** https://pta6.vercel.app

## Controls

| Key | Action |
|---|---|
| WASD | Move, drive, swim |
| Mouse | Look and aim (shots go where the crosshair points) |
| Left click / Space | Attack (Space is the handbrake in a car) |
| Right mouse / X | Aim |
| R | Reload on foot, radio in a car |
| 1-5 / Q / wheel | Switch weapon |
| F or E | Enter or exit a vehicle |
| Shift | Sprint |
| C | Jump |
| T | Phone |
| M | Map and waypoints |
| B | Buy |
| F near Vinny (pink) | Chapter 1 story, then contracts |
| F near Rico (cyan) | Chapter 2 after Vinny |
| Y near skull | Rampage |
| J | Side job, or cancel the current one |
| V | Store the current car at a safehouse you own |
| Phone 9 / 0 | Hit contract / chop shop order |
| P | Pause and stats |
| G | HD or pixel graphics |

Touch controls appear automatically on phones and tablets.

## City work

Vinny (pink) runs eight chapter-one jobs, then contracts. Rico (cyan) opens chapter two with chop shop work, hits, escorts, and a kingpin finale. Respect builds from missions, turf, races, rampages, and stunt jumps. Press J in a taxi, police car, ambulance, or fire truck for side work, or at the orange race marker for a street race. Skull markers start rampages. Yellow stunt ramps pay cash at speed. Three gangs hold turf; clear the crew to take the block. At three wanted stars the police drop roadblocks. The phone also orders hits and chop targets.

## Run locally

Open `index.html` in a browser. It loads three.js from a CDN, so it needs an internet connection.
